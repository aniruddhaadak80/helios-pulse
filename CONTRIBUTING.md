# Contributing to HELIOS PULSE ☀️

Thanks for stopping by! Good first issues: `aurora-map`, `donki-timeline`, `webpush`, `og-cards`.

1. Fork → branch (`feat/aurora-map`) → PR with a screenshot or Loom.
2. `npm install && npm run dev` — the app works with zero keys (live NOAA/USGS, graceful fallbacks).
3. Keep it honest: never imply solar activity *causes* earthquakes; link NOAA SWPC for alert claims.
4. Small, focused PRs merge fastest. MIT licensed — your contribution will be too.
